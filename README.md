# KiDudu Store 🛍️

Projeto desenvolvido como freela para a loja **KiDudu**, localizada em Belo Jardim - PE.

O objetivo do site é promover a loja online, apresentar os produtos de forma moderna e facilitar o processo de compra para os clientes.

---

## 🚀 Funcionalidades

* Catálogo de produtos
* Layout responsivo
* Carrinho/modal de compras
* Interface moderna utilizando TailwindCSS
* Estrutura otimizada para deploy web

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* TailwindCSS
* Webpack

---

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/felps1z/kidudu.git
```

Acesse a pasta do projeto:

```bash
cd kidudu
```

Instale as dependências:

```bash
npm install
```

---

## ▶️ Rodando o projeto

Execute o comando:

```bash
npm run dev
```

Os arquivos finais serão gerados na pasta `dist/`.

---

## 🌐 Deploy

O projeto está configurado para deploy utilizando GitHub Pages.

Para publicar:

```bash
npm run deploy
```
